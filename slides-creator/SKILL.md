# Slides Creator — Compatibility Notice

Treat this entry as a retirement notice. Slide creation was retired on 2026-08-07;
the distributed package contains this notice, not the former narrative workflow
or visual-generation delegation. Do not use it to generate a slide deck.

Keep the existing `slides-creator` identity for installed-plugin compatibility.
An invocation can explain this status; it cannot restore the retired workflow.
This entry is scheduled for removal in a future major release.

For a new presentation, use `deck-creator` only when it is already installed;
otherwise select a presentation workflow actually available in the current host.
No replacement builder is bundled with this notice; do not promise access to a
private edition.
