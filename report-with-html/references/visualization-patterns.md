**本 skill 认可图的共同 DNA**（判断层给形式，这条给"整页长什么样"）：**全景看板** = 一张 overview 表（维度 = 行 + 每行 `→` 锚跳）+ 每个 detail section 一个**不同问题**、不同几何；**决策视图**让匹配、权衡、未知、路径和缺口各回答自己的问题。**没有任何实体 / 维度被换个形状画第二遍**（这条的通用判据在判断层的"一个对象只画一次"）。

**报告页专有的反模式**（通用反模式清单在判断层，此处只列本 skill 独有的）：
- **AI slop**（签名清单 SSOT 见 `design-principles.md` §AI slop 签名，此处不复述）→ 回 `approved-examples.md` 挑最近 register 的样例重校准。
- **屏上出现内部黑话 / 裸算法分 / 未解释缩写** → 去黑话，见 `design-principles.md` §9 受众落地。
- **自造几何没配「编码 = 含义」解码句** → 解码句给读法、mark 标值给数、读出句给事实性 takeaway，三者配套才让图**自包含**（见 `design-principles.md` §2/§11）。

**几何组件的 HTML 实现约定**：全部只用 flex + border + inline `width%`/`height%` + 一个 `::before`/连接符，**无需图表库**——保证单文件产物自包含。

**统计图表的实现**：用当前项目已声明的图表栈或已安装的成熟可视化能力；两者都没有时先调研并选维护中的库，**禁止手搓图表引擎**。mark 规格按判断层的 house 风格校准——**库的默认坐标系和皮不是交付标准**。

## 表格的 HTML 实现规格

> 表格**该留几列、哪些数值该编成图形、和图重复怎么办**——判断层的事，见 `data-visualization-discipline` 的表格纪律。这里只管 HTML 落地怎么写。

让表"数据前置、骨架后退"的类型学微规格：

- **表头降调**：小一号灰字（11–11.5px、ink-3、`letter-spacing .05em`）+ 底 1.5px 重线——表头是骨架不是内容，退后。
- **行首锚列**：加粗 + `white-space:nowrap` + `width:1%`（serif 可选）——每行的"主语"窄化钉死在行首，其余列给数据。
- **数值列右对齐**（`text-align:right`）+ tabular-nums——位数对齐才能竖扫比大小。
- **hero 数"值大单位小"**：大号 mono 数字 + 缩小的灰单位（24–34px 值 vs 12–15px 单位，`1,563 <small>条</small>`）——number strip 与统计卡通用。
- **React 工程里用项目真表格组件**（Antd / TanStack），别手搓坏表；纯 HTML 报告页则手写紧凑表 + tabular-nums 对齐。

## 版面填充纪律：铺满画布、消灭空洞

（2026-07 半年报密度反复踩）

原话："**信息密度很差，大量排版错误和空白。**" 报告页留大片空白 = 密度失败。三条硬动作：

- **N 个视觉用网格均分铺满**：一页放 4 个视觉 → `2×2` 网格等高等宽填满，不是两列摞成"上半页挤、下半页空"。`flex + justify-content:space-between` 会把内容顶到上下两端、**中间留一个空洞**（比底部空白更丑）——用 grid 均分，别拿 space-between 硬撑高度。
- **脚注 / 口径走正常文档流，不用 `position:absolute`**：绝对定位的脚注**不占位**，flex 内容流到底部就和它**重叠糊成一团**（战例：一句绿色注解压在灰色脚注上、两层字叠一起）。让脚注是最后一个流内元素、`margin-top` 拉开，内容自然堆在它上方。
- **每一页都渲染出来 Read，不只第一页**：多页产物只看第一页 = 漏掉后面页的碰撞 / 空洞 / 溢出；必须逐页用**目标浏览器**截图并检查。

## 页序 = 叙事节奏

（2026-07 半年报 4→3 页重排沉淀）

判断层的"分解轴清单"定完**有几页**，还要定**谁在前谁在后**：

- **核心诉求不埋最后**——读者（尤其高管）要的那个洞察放开场，别铺垫一堆再压轴。战例：客户方要"营销共振"，共振却排第 4 页；提到第 1 页开场即讲透、趁热回应。
- **问题 / 机会型洞察压轴收尾**——"资源错配、账号多的省在沉睡"这类，放开场是泼冷水，放结尾变"下半年激活空间"的前瞻钩子。战例：区域倒挂从第 1 页挪到末页压轴。
- **因果是一回事、别拆两页**——"成绩(果)"和"产生成绩的机制(因)"拆两页，成绩页只剩数字显空、机制页又孤立。战例：半年报把"成绩单"和"营销共振"拆两页 → 成绩单空得慌、共振悬着 → 合并成一页"营销共振(成绩果 + 机制因)"，一页讲透还消灭了空页。**一页撑不满常是信号**：它和另一页本是一体，合并 > 硬填（根治在结构不在填充）。
