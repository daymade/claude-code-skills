# 认可的报告页 · 校准语料库

点名认可的报告页与工具页。原话："**信息密度、可读性、信息完整性、可视化、能不能快速理解、结构化，这些做得非常好。你来学，到底什么是我想要的。**"

**用法（像 content-writing-discipline 读 golden-samples）**：动手写任何报告页前，**先打开与当前 register 最接近的真实样例**，抽它"为什么好"的具体做法，再实例化。规则表达不出整张的信息密度/节奏/密实感——只有真样例能校准。仓内样例优先从 `assets/examples/` 打开；未复制的私有工具页只使用下表登记的明确路径，禁止自行扫描个人暂存目录找样例。

**收录闸**：只收**亲自认可**的页（原话/明确点头），收录时标 register——未认可的再漂亮也不进，语料纯度＝校准可信度。收录是历史事件，保留确认日期；语料数量、文件体积等可由目录与表格现算的值不持久化。当前没有同 register 样例时，读结构最近邻和原则，交付时明确说明校准依据。

## 共同 DNA

1. **信息密度高但能扫读**——塞得满，但靠分区 / 分组 / 视觉编码让人一眼扫；不是文字墙，也不是稀疏留白。
2. **每块自带一句 lead**——章节/卡片开头先说"这块讲什么"，读者不用猜。
3. **数字 mono 突出 · 状态/评分/占比全视觉编码**——评分=填格条、把握=进度条、状态=badge、占比=堆叠条；**不用文字描述能用图形的**。
4. **真实证据优先**——内容是视觉的就 show 真的（真实镜头缩略图 / 视频播放器 / 真实截图），不用抽象方块代替。
5. **结构化组件词汇丰富**——见下方组件表；每种组件的布局本身编码含义。
6. **诚实的完整性**——可下钻全貌（折叠原文 / 详情）、可溯源、留纠错入口；不藏、不假全绿。**极致形态是"摊开给你看"**：被问"你测的是什么/你在干什么"时，把提示词全文、测试判据、待核项原样披露（机制透明页）。

> 皮（颜色/字体/是否印章）随 register 变，但上面的 DNA 不变。这就是"泛化"的落点：学 DNA + 组件，不抄某张的皮。
> 工具页（浏览器/工作台）同样满足这些判据，并要求**可移植的自包含交付**与**hash 可分享定位**（`#g=群名` / `#p1` 直达，引用时给"URL#锚点"不给裸编号）。

## 组件词汇（从语料抽出的可复用件 · 布局即含义）

结构组件（皮随 register 换，结构复用）：
- **泳道价值流**（zones × pill+badge + loops）—— 用户旅程/价值流，横=流动、zone=分段、badge=状态。
- **管道 + 深色 goal 节点** —— 流水线，终点用深色块收束。
- **机制链**（start 底色→goal 深色 + **edge 语义标签**）—— 因果机器：节点是状态、边上写"为什么会走到下一步"（她需要/换回）；比裸箭头多一层因果语义。
- **横向时间轴**（dot: 实心=已定/空心=可选，when/what/desc）—— 节奏/演进；关键 caveat 红字标。
- **镜像对比**（两实体卡 + ≈/vs + 属性 dl，active 红框）—— 两个同构对象比对；**＋缺口条变体**：两卡下压一条虚线红框"缺口＝X"，对比的落点是那道缺口。
- **价值栈**（上薄=核心独有/下宽=commodity + 每层"对方怎样"）—— 对比揭示价值集中在哪层（见 visualization-patterns）。
- **价值交换 give⇄get** —— 双列交换清单（key 项加重）＋底部跃迁行（从什么身份→到什么身份）。
- **可控性阶梯**（层×承诺形态）—— 风险/事项按可控性分层，每层对应不同的承诺强度（硬承诺/区间/只计量）。
- **处境→杠杆映射行**（左=对方处境 ▸ 右=我方供给）—— 对手分析落到自己的抓手。
- **收敛节点**（变体 chips ──▶ canon 红框）—— 多变体归一；数据清洗/实体对齐通用。
- **文档树**（SSOT root + └ 派生分支）—— SSOT/派生关系；**＋改动热度变体**：枝上标本次改动量（skill 改动页）。
- **飞轮/timeline** —— 循环/路线。
- **number strip** —— hero 数（mono tabular-nums）。
- **多页分解轴** —— 一页一个分析轴，页序=叙事节奏（核心诉求开场、机会压轴），任何量不跨页重画。

决策·透明组件（AI 抛决策/自证透明时用）：
- **待拍板卡**——完整定义与 CSS 类只认 `design-principles.md` §10；引用的图/条款直接内嵌，拍掉的移进"已定"，待他人项分开标。
- **before/after 差分对照**（现状｜→｜之后；chip=已有、虚线框=空洞、划线=被填）—— 把"这个决定改变什么"画成差分，不是散文描述后果。
- **证据对照表**（来源｜原话（斜体）｜落实点｜状态 tag）—— 逐条纠正→落实的核对账；**查不到解释的如实标"待核"**，不硬标全绿。
- **认可 vs 缺口**（实框=已有 vs 虚线框=缺的那格）—— 可视化"这页存在的原因/还差哪格"。
- **五步 case 卡**（真帧＋人审角标 → 素材｜人审原话｜**原话→考题转换**｜AI 实答（过/拦色块＋期望）｜判定＋why）—— 测试机制透明化：样本一过一拦各走一遍全流程。
- **全文分节披露**（分区标题＋增量归因绿标"这段来自谁的反馈"）—— 提示词/规则全文原样放出，新增段落标注来源，不摘要不遮掩。
- **落库对账 footer**（commit hash＋已推/未推色标＋待用户 todo 框）—— 报告页背后的持久化状态也交代，链到下一步动作。

数据/评分组件（把"数值/等级/占比/状态"变图形）：
- **填格条**（▓▓▓▓░ + 数字）—— 离散评分。
- **进度条** —— 连续把握/百分比。
- **堆叠占比条** —— 份额/构成。
- **梯队条漏斗** —— 阈值逐级收窄。
- **双增长 combo**（柱×线）—— 两个相关量同涨（账号数×单号产量＝共振）。
- **tornado 双向条** —— 两个量的倒挂/错配（账号多⇄播放少），实体双向混选。
- **分段条** —— 时间轴内的段落（镜头结构/可用段）。
- **标签行（tags）** —— 分类/属性 chip。
- **verdict banner** —— 人审结论横幅（✓认可 + 备注）。
- **实体×指标矩阵**（m-cell）—— N 实体逐项明细，一张矩阵不重画（四家页）。

交互组件（当交互能帮理解时才上）：
- **计算器**（滑块 + preset 按钮 + 实时联动数字流 + 高亮结果 + 解释句）—— 让读者拨动参数看结果，比静态数字更懂。
- **折叠手风琴 / collapsible** —— 概览不丢细节：默认收、点开看全貌；组带 id ＋ hash 自动展开。
- **嵌入源文档抽屉**（文档 tab 导航＋条款锚点＋正文引用自动 linkify→侧滑抽屉定位高亮）—— 审阅页"每句话可核到原文"的实体；全文是烤进页面的**快照**，必须配生成器并用 `--check` 验证同步（纪律 `long-lived-report-maintenance.md`＋模板 `assets/regen-docs-template.py`）。
- **sticky nav** —— 长页锚点导航。

工具页组件（浏览器/工作台专用）：
- **side+main 双栏** —— 列表（分组＋计数）＋详情流，数据集导航的基本骨架。
- **hash 路由直达** —— `#g=群名`/`#p1` 让任何条目可被链接引用、可分享定位。
- **badge 状态流转** —— 待审/处理中/已审/失败/有问题，工作流状态即视觉。
- **filter chips ＋搜索** —— 大数据集的切片入口。
- **人工标记＋导出回流**（flag-select ＋导出审核 JSON）—— 人审产物结构化回流给机器，审完不是终点。
- **媒体对照审**（音频播放器/视频贴着数据卡）—— 判断素材贴着原始证据，不凭转写文字空判。

真实证据组件：
- **真实缩略图带 / 视频播放器 / 真截图** —— 内容是视觉的就 show 真的（explainer 真帧、探针审核真视频），不用抽象方块代替。

## 反面（这批都没有 · 出现即偏离）
文字墙 / 纯表格堆屏（松垮像 Excel）/ 无空间语义的方块阵 / 无证据锚点的价值判断或口号 / 全绿假状态 / **AI slop（签名清单 SSOT 见 `design-principles.md` §AI slop 签名）** / 内容明明是视觉却用文字描述代替真图 / 屏上术语带内部黑话受众读不懂（见 `design-principles.md` §9）/ 查不到解释的数据硬标"已核"（该标"待核"就标）。
