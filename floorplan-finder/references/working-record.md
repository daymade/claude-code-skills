# Working record

Use this for a search that spans interruptions or several candidate images. Keep
it in the authorized task directory, outside the Skill bundle. An in-context table
is sufficient for a short task; do not create another memory system.

Copy only the sections needed. Fill unknowns visibly and distinguish a site claim
from an occupant's confirmation. Preserve later corrections and the candidate to
which an answer applies; do not restart with the original, narrower scope.

Keep passwords, phone numbers, one-time codes, signed media URLs and unrelated
history out of this record. Link to authorized private originals where necessary;
do not copy private home identities into public examples or reusable fixtures.

On resume, verify the current page/resource state, reread the latest user correction,
and start at the first unmet requirement. Reuse prior inspected originals unless
their identity changed or a new contradiction requires another look.
