# Prepare identity-document copies from existing photos

Use this branch for printable ID/passport copies. Reuse suitable existing photos;
do not require a new scan merely because the input is a photo. Preserve the
document's visible contents. Do not invent a missing side, page, number, portrait
or signature, or use the digital-signature synthesis branch on an identity document.

## Bind the requested copy

Read the recipient's current instructions and any supplied example before laying
out the page. Record each required side/page, required spread, size/scale, paper
size and accepted form. Keep unspecified requirements unknown; do not turn one
institution's instructions into a universal rule.

Distinguish a photo printout, a scanned copy and a photocopy made from the original.
Image processing does not change which one was produced. If the recipient
explicitly requires copying from the original, report that requirement before
presenting a photo printout as usable. An additionally requested photo version may
still be prepared and labelled accurately; it does not satisfy that requirement.

Build this table from the source images, before processing:

| Material | Required sides/pages or spread | Actual source coverage | Missing or unreadable part | Output page(s) |
|---|---|---|---|---|
| ID copy | As requested by the recipient | Identify each supplied side | Exact missing side, if any | Planned mapping |
| Passport copy | As requested, including the full spread when specified | Identify each visible page and boundary | Exact missing page/region, if any | Planned mapping |

Inspect the whole source, including edges and the other page of a required
spread. Readable names, signatures or machine-readable lines alone do not prove
coverage. If a required part is missing, continue independent complete materials
and request only that missing source or the required original-copying action.
Do not certify the incomplete material as ready or repeatedly request all documents.

## Process and verify

Use the existing photo pipeline where applicable, preserving legibility and
document content. Avoid cropping document edges or applying whitening that removes
faint text, patterned backgrounds or security details. Inspect the processor's
crop/resize behavior before applying it to an ID or passport.

Keep opposite sides at the recipient's requested matching size. If an actual-size
copy is required, verify the intended physical dimensions in the final PDF and
the printer's scaling options; fitting an image to A4 does not establish scale.
If the source or tools cannot establish the required dimensions, report that gap.

Read the final PDF's rendered pages and reconcile every table row: correct sides,
complete spread, visible edges, orientation, requested scale and readable detail.
Retain the table with the task's output, outside the update-owned Skill bundle.
Label the result as the copy form actually produced. PDF verification establishes
the file's coverage and appearance; physical output and recipient acceptance need
their own observations from the printing/receiving workflow.
